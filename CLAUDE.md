# CLAUDE.md — что специфично для Claude Code

Все правила проекта — в [AGENTS.md](AGENTS.md); здесь только то, что касается именно этого клиента.

- **Скиллы видны через `.claude/skills`** — это символическая ссылка на `.agents/skills`. Отдельной копии скиллов для Claude Code нет: правится файл в `.agents/skills/<имя>/SKILL.md`, и он же сразу виден как скилл.
- **Субагенты: Opus там, где есть суждение** — досье к фильму, страница создателя, письмо и логический проход по тексту. Sonnet — справочная карточка и механические проходы вроде сверки формы по первым строкам. Зоны сбора материала по моделям не разводим: статус факту ставит зона, а это суждение. Источник правды — строка «Модель:» в `SKILL.md` каждого скилла.
- **`next dev` убивать по pid**, а не по имени процесса: `kill $(lsof -tiTCP:3000 -sTCP:LISTEN)`. `pkill -f next` заденет чужие серверы разработки, запущенные рядом.
