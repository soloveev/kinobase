## 2026-09-22 — Версия 1: отчуждаемая база

Собрана из персонального проекта автора вычитанием личного: без страницы «О проекте», админки и ссылок на канал; личные константы — в `src/site.config.ts`, файлы данных — в `content/`. Демо — пять фильмов: два с полным досье, один с блоком «Зачем смотреть», два только со справкой. Скиллы наполнения, правила текстов, шаблоны сервера и документация — в репозитории; поисковые ключи необязательны. Первый заход агента — `.agents/skills/kinobase-setup`.

Перед публикацией — четыре цикла проверки свежим агентом: чистый клон, агент без контекста разворачивает базу по `README.md` и скиллу `kinobase-setup`, проходит онбординг и сдаёт отчёт. По итогам циклов `.env.example` едет в гит, название сайта берётся из конфига везде, тесты не зависят от заполненного `src/site.config.ts` (мок в `vitest.setup.ts`), токен владельца берётся из локального `.env.local`. Четвёртый цикл прошёл без вопросов и ошибок. Опубликовано 22.09.2026, README со скриншотами.
