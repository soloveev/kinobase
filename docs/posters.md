# Постеры фильмов

В «Кино Базе» постеры — это статические файлы в `public/posters/`, а запись фильма в базе ссылается на них полем `posterPath` вида `/posters/<slug>.jpg`. Никакой загрузки картинок по сети во время работы сайта нет: что лежит в репозитории, то и показывается. Поэтому добавление фильма всегда включает отдельный шаг «положить постер».

Договорённость по содержанию зависит от происхождения фильма:

- **у российских фильмов — русский постер.** Для отечественного кино родной плакат и есть официальный: именно его рисовали к прокату, а англоязычная версия — экспортный фестивальный вариант. У «Непокоя» стоит русский прокатный плакат.
- **у всех остальных — международный:** англоязычный прокатный или вовсе без надписей. Русские локализованные версии зарубежных фильмов не используем — сетка смотрится единообразно, только когда у плакатов один язык типографики, и этот язык у нас английский.

## Два размера

Начиная с пятой версии постер кладётся в двух размерах, потому что живёт в двух местах:

| Файл | Размер | Где показывается |
|---|---|---|
| `public/posters/<slug>.jpg` | `w780`, 780 × 1170 | сетка на главной, левая колонка карточки |
| `public/posters/original/<slug>.jpg` | `original` | полноэкранный просмотр по щелчку на постере |

Имена файлов одинаковые: страница выводит путь к полноразмерному из рабочего по соглашению, отдельного поля в базе нет. Если полноразмерного файла нет, полноэкранный просмотр покажет рабочий — сайт не сломается, но рассматривать будет нечего.

## Требования к файлу

Вертикальный формат 2:3, формат JPEG. Рабочий файл — размер `w780` у TMDB, то есть 780 × 1170 пикселей: этого хватает и для карточки в сетке, и для страницы фильма при экранах с удвоенной плотностью, а весит такой файл 100–400 КБ. Полноразмерный — `original`, обычно около 2000 × 3000; если он тяжелее 3 МБ, берём вместо него `w1280`: репозиторий не место для десятков мегабайт картинок. Имя файла — латинский slug фильма (`twilight-of-the-warriors.jpg`), совпадающий с тем, что записано в `posterPath`.

Перед тем как класть файлы, стоит убедиться, что они действительно скачались и не являются страницей с ошибкой:

```bash
file public/posters/<slug>.jpg           # "JPEG image data ... 780x1170"
file public/posters/original/<slug>.jpg  # "JPEG image data ...", ширина заметно больше 780
```

## Где искать

Основной источник — **TMDB** (The Movie Database). У него есть программный интерфейс (API), но он требует ключа, которого в проекте пока нет. Зато сайт TMDB отдаёт те же данные обычным HTTP-запросом без авторизации, и этого достаточно.

Поиск фильма и получение его числового идентификатора:

```
https://www.themoviedb.org/search?query=<название, urlencoded>
```

В ответе идентификатор виден в ссылках вида `href="/movie/701387-bugonia"`. Убедиться, что найден нужный фильм (одноимённых много), проще всего по странице `https://www.themoviedb.org/movie/<id>` — там в заголовке год, а в блоке съёмочной группы режиссёр.

Галерея постеров с фильтром по языку:

```
https://www.themoviedb.org/movie/<id>/images/posters?image_language=<lang>&image_sort=rating.desc
```

Ссылки на полноразмерные файлы лежат в HTML как `https://image.tmdb.org/t/p/original/<file_path>.jpg`. Скачивать нужно не `original`, а нужный нам размер, подставив его в тот же путь:

```
https://image.tmdb.org/t/p/w780/<file_path>.jpg
```

Если на TMDB подходящего варианта нет, следующие места — impawards.com (архив американских прокатных плакатов, разбит по годам и по фильмам), медиараздел страницы фильма на IMDb и сайты дистрибьюторов (для фестивального кино это чаще всего Neon, A24, Mubi, Sony Pictures Classics). Для российских картин с международным прокатом полезны страницы фильма на сайтах фестивалей — у «Непокоя» англоязычный плакат нашёлся именно как фестивальный.

## Как отличить локализованную версию от международной

Ключ ко всему — язык надписей на постере, и TMDB хранит его отдельным полем. В API это `iso_639_1` у каждого элемента массива `posters`, в адресах сайта — параметр `image_language`. Значения, которые нам важны:

- `en` — надписи на английском, то есть международная или американская прокатная версия;
- `xx` в адресе сайта (и `null` в ответе API) — постер вообще без текста, «textless»; такие подходят всегда, но их обычно мало;
- `ru` — русская локализация: то, что мы берём для российских фильмов и заменяем у зарубежных.

Важная тонкость: **язык надписей не связан с языком оригинала фильма**. У испанского «Сирата» есть англоязычный плакат международного проката, у гонконгской «Осады Коулуна» — тоже. Если для неанглоязычного зарубежного фильма ни `en`, ни `xx` не нашлось, берём оригинальную версию на языке производства (`es`, `zh` и так далее), но не русскую.

Ещё одна тонкость: сортировка `rating.desc` поднимает наверх то, что нравится пользователям TMDB, а не то, что было официальным плакатом. Среди верхних позиций попадаются фанатские работы и кадры с наложенным названием. Поэтому выбранный вариант нужно посмотреть глазами: официальный плакат узнаётся по аккуратной типографике, кредит-блоку внизу или логотипу студии, а у фанатского обычно «слишком чистая» композиция без единой служебной надписи.

## Рецепт: добавить постер новому фильму

1. Найти фильм в поиске TMDB и записать его числовой идентификатор; сверить год и режиссёра на странице фильма, чтобы не взять однофамильца.
2. Открыть галерею постеров: для российского фильма — с `image_language=ru`; для зарубежного — с `image_language=en`, при пустом результате с `image_language=xx`, при пустом и там — с языком оригинала.
3. Выбрать вариант: приоритет у официального прокатного плаката с полностью читаемым названием. Отдельно проверить, что название не обрезано краем кадра — среди загрузок TMDB попадаются кропы широких баннеров.
4. Скачать выбранный `file_path` **дважды под одним и тем же именем-слагом**: в размере `w780` в `public/posters/` и в размере `original` в `public/posters/original/`.
5. Проверить оба файла командой `file`: должно быть валидное `JPEG image data`, у рабочего — около 780 × 1170 и вес больше 10 КБ, у полноразмерного — ширина заметно больше 780. Если полноразмерный тяжелее 3 МБ, перекачать его в размере `w1280`. Только после этого перезаписывать существующие файлы, если речь о замене.
6. Прописать `posterPath: "/posters/<slug>.jpg"` в данных фильма. Путь к полноразмерному нигде не записывается — он выводится из этого по соглашению об имени.

При замене постера у уже заведённого фильма достаточно перезаписать оба файла под теми же именами — ни `content/films-data.json`, ни база не меняются. Заменять нужно именно оба: разъехавшиеся рабочий и полноразмерный дадут разные плакаты в сетке и в полноэкранном просмотре.

## Что стоит автоматизировать

Ручной разбор HTML — временное решение, вызванное отсутствием ключа TMDB. Как только ключ появится (он бесплатный, выдаётся в настройках аккаунта), всю выборку заменит один запрос:

```
GET https://api.themoviedb.org/3/movie/<id>/images
```

Ответ содержит массив `posters`, где у каждого элемента есть `file_path`, `iso_639_1`, `width`, `height`, `vote_average` и `aspect_ratio`. Этого достаточно, чтобы отобрать кандидатов программно: фильтр `iso_639_1 in ('en', null)`, отсечка по `aspect_ratio` около 0.667 и сортировка по `vote_average`. Дальше файл нужно скачать в двух размерах — `w780` и `original` — и проверить их размеры любой библиотекой для работы с изображениями.

Логичный вид такой автоматизации — скрипт `scripts/fetch-poster.ts`, который принимает идентификатор TMDB и slug, кладёт файл в `public/posters/` и падает с внятной ошибкой, если ни одного подходящего постера нет. Человеческий шаг «посмотреть глазами» полностью убрать не выйдет: отличить официальный плакат от фанатского по метаданным нельзя. Разумный компромисс — скрипт предлагает трёх-четырёх кандидатов, а выбор остаётся за человеком. Этот сюжет естественно ложится в задачу седьмой версии «исследовать бесплатные API и сделать автозаполнение» из [kanban.md](../kanban.md).
