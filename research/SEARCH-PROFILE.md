# Профиль поиска

Профиль не задан: онбординг (`.agents/skills/kinobase-setup`) ещё не пройден.

Пока файл в таком виде, скиллы наполнения считают профиль **встроенным**: поиск и чтение страниц — встроенными инструментами агента, по правилам `SOURCING.md`, раздел «Инструменты и порядок чтения». После онбординга здесь стоит одна из трёх ступеней и перечень ключей, которые лежат в `.env.local`:

| Ступень | Что есть | Чем ищем и читаем |
|---|---|---|
| Полный | Exa, Tabstack, Parallel | Exa ищет, Exa Contents или Tabstack читает, Parallel добирает |
| Частичный | часть ключей | шаг без сервиса — встроенными инструментами агента |
| Встроенный | ключей нет | встроенные поиск и чтение агента |

## Как выглядит заполненный файл

После онбординга первые строки заменяются на такие; таблица ступеней остаётся, этот раздел-образец удаляется:

```
# Профиль поиска

Ступень: встроенный. Заполнено 22.09.2026 по онбордингу.
Ключи в `.env.local`: нет. Поиск и чтение — встроенными инструментами агента по `SOURCING.md`.
```

или

```
Ступень: частичный. Заполнено 22.09.2026 по онбордингу.
Ключи в `.env.local`: EXA_API_KEY. Tabstack и Parallel — нет: чтение страниц — Exa Contents, запасное чтение — `r.jina.ai` и `curl`.
```
